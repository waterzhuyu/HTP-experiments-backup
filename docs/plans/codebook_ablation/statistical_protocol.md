# 容量效应统计口径补充（正式结果产生前）

状态：已实现并通过合成数据验证，未读取正式pilot结果。训练源码工作区保持52b6666不变，统计源码在独立analysis/codebook-capacity分支。

输入必须是按相同capacity、seed和traj_id对齐的B2/H1逐轨迹主误差，失败样本保留固定惩罚，不能只对成功样本作主要判断。每seed效应为1−mean(H1)/mean(B2)，汇总采用三个seed效应等权平均。五档都完成后才作总体判断，缺少任意run时拒绝宣称完成。

同一验证轨迹在所有seed及容量下被重复使用，因此采用seed与trajectory两个交叉维度的重采样：每次有放回抽3个seed和1024个traj_id，抽样索引在所有容量及B2/H1之间共享；不是把同一轨迹的跨seed结果当独立样本。10000次，seed271828。报告95%区间、seed标准差和原始每seed数值；只有3个seed，bootstrap不能凭空补充训练随机性的证据。

五个容量效应的一侧同时上界使用Bonferroni分位数1−0.05/5；四个相对base交互使用双侧Bonferroni分位数0.05/8与1−0.05/8。实用收益阈值5%，交互等效界±5个百分点。所有效应上界小于5%才支持排除已测范围内≥5%的收益；所有交互区间落入±5个百分点才支持已测范围的效应稳健。仍需结合码本利用和probe判断名义容量是否真正被使用。

额外给出中心化bootstrap近似p值，并对5+4个对比一起Holm校正，作为描述性统计；最终判断使用上述同时区间，而非不显著即等效。程序测试包括恒等零效应、已知9个百分点容量交互、训练seed分歧导致宽区间以及非法数组拒绝。
