# 独立 latent → 分层 SID：完整单 seed 探索结果与改进意见

状态：completed（四组pilot与补充分析完成）；日期2026-09-17。科学判断：当前HV未通过预设探索门槛，不进入方法升级或扩规模阶段。没有确认性、多seed或跨域收益声明。

## 结论与判断边界

1. **目前不能把“独立latent→视图条件分层SID”当作有效改进。** 主比较HV−LF的G11相对改善为−2.787%，普通95%轨迹bootstrap区间[−14.058%, +4.359%]，预定四个G11对比的同时区间[−17.971%, +5.581%]。未达到≥5%且区间支持改善的门槛；跨零不是等效证据。HV前两层码分布高度集中，四组后两层均未通过码本健康门槛。
2. **共享encoder的H1仍是实用参照，而非已证明优于B2的新方法。** LF和HV相对H1的G11分别恶化5.883%和8.834%，其同时区间均为负改善；H1相对B2仅改善0.305%，区间跨零。此处区间只描述这批轨迹上的不确定性，不包含训练随机性。
3. **LF并非所有方面都退步。** 使用真实SID/真实sampling的G00，LF位置ADE为166.39m，优于H1的178.92m（配对差−12.52m，95%区间[−18.84,−6.84]）；但生成SID的G11，LF为284.45m，差于H1的273.72m（差+10.74m，[+1.22,+20.00]）。真实码重构与可生成性必须分开优化，不能用单一probe或NLL排名代替端到端结果。
4. **HV较低NLL与较高tuple正确率不能证明语义更好。** HV第一层94.696%预测准确率几乎等于94.680%的最大码占比；其平均相对训练unigram收益为0.514 nats/token，低于LF .663、H1 .650、B2 .754。unigram忽略路线、历史事件和前层条件，只是描述性参照，不是匹配条件模型。

## 方法、控制与复现

完整具体方法以同目录`spec.md`、`pilot.json`、训练revision `70b82db195f600e3271030ddb5e6c228e4915f31`及每组解析配置为准。本报告没有引入新训练或修改原结果。上游revision `1294275d2bed5f9de86269ab285ff5e23828b947`，实验fork `52b6666e6a65eeee7fbe7ecc7cae8b84548f7ea3`；与上游直接比较不属于本轮四组实验。

Porto官方train内固定8192训练/1024验证整条轨迹，20–200点，GPS/time哈希去重，split seed20260907、训练seed42。三视图按traj_id/point_index一一对齐；不读封存official test。道路、车辆、日期可重叠，不能声称对应的OOD泛化。GPS为MBR归一化经纬度，Grid=100m ID，Road=逐点匹配道路ID；dxy原单位km、percent使用训练集z-score，time秒仅诊断。真实route同时作为LLM/decoder条件。

输入GPS B×T×2与Grid/Road B×T；变长mask屏蔽padding。GPS Linear2→64+LN，Grid Embedding64+LN，Road可训练Node2Vec128初始化embedding→Linear64+LN。HTP encoder hidden64/ch_multi[1,2,2,4]/每级2残差块/dropout.1/三次stride2，256→64 projection；每轨迹ceil(T/8)个event，监督支持8j:min(8j+7,T−1)，实际感受野更大，不是独立8点窗口。

四层64维码本K=32/64/128/256。HV按Grid、Road−sg(s1)、GPS−sg(s2)、GPS−sg(s3)作最近邻量化，s_l为累计码向量；L_vq=四层均值[MSE(q_l,sg(t_l))+.25MSE(t_l,sg(q_l))]。码本仅接受本层局部VQ更新，前缀残差detach。HV decoder ST为z_g+sg(s4−z_g)，仅回GPS；各辅助ST只回自身encoder。LF的z=(z_grid+z_road+z_gps)/sqrt(3)，标准RQ，所有重构/辅助梯度经z回三个分支。码字求和后Linear64→256、route-conditioned decoder预测percent+dxy，经道路几何和反归一化恢复GPS；无连续旁路。

总损失为L_percent+L_dxy+L_vq+.1L_grid+.1L_road+.1L_gps；前两项为batch有效元素MSE；辅助为64维前缀+8维offset→64SiLU→目标，GPS归一化MSE，Grid/Road CE除log训练词表大小，按轨迹有效点平均再batch平均。无usage、采样一致性、互斥或covariance训练损失，继承日志中的同名遥测不等于新增目标。tokenizer从头训练，Road向量只是初始化且可训练；1280step/20epoch、batch128、AdamW1e−4/wd1e−4/clip1，warmup10epoch起始倍率.01后cosine到.1，BF16，量化及CE FP32。

冻结tokenizer后，Qwen3-1.7B LoRA r16/alpha32/dropout.05，q/k/v/o/gate/up/down，base冻结、新token行训练；micro2×accum8、1024step/2epoch、AdamW lr5e−4/wd1e−4/clip1、linear warmup.05、BF16+checkpointing。生成greedy/batch1/max_new_tokens256，不重试失败。其他细节见spec；四组实际预算均验收一致。

## 评估定义与完整性

G00真实SID/真实sampling，G10生成SID/真实sampling，G01真实SID/生成sampling，G11均生成。主指标为四项km统计量abs(log1p生成−log1p真实)的平均，无效固定1，敏感性10；不是ADE、相对误差百分比或物理时间误差。1024条全人口、保留失败。HV仅traj58954生成截断、缺结束标记，G10/G01/G11各含同一失败；其他组无失败，无重跑。

配对bootstrap2000次、seed271828，以轨迹为单元、各组共用抽样权重；主比较HV−LF，四个预定G11对比另报Bonferroni同时区间。共同成功GPS在100个观测索引进度锚点线性插值后计算ADE/FDE，涉及HV的生成条件剔除1条并显式记录，其他1024条；不是时间对齐。成功集GPS不能替代全人口惩罚指标。原JSD使用各自产物分箱，不以它作主要组间因果结论。

四组各24个冻结probe均10epoch/1860step，train47533/val5996事件、seed42、AdamW.001/wd.0001/batch_events256、MLP64；输入单层/累计码向量加offset、按有效点逆轨迹长度加权。未添加常量probe参照，故只解释同协议相对差异，不把低绝对准确率或CE等同于信息量。

tuple补评为保存adapter冻结、teacher batch4，无训练；5996目标事件，四码同时正确才计对。自由生成按目标事件序号对齐，缺失/失败计错，额外事件单列，不是语义或时间对齐。恢复NLL差必须≤.005且token/层分母一致，四组均通过；恢复评估不覆盖原评估。

采样诊断仅取原点索引0::2或0::3并强制保留末点；按真实时间将GPS线性插值回全部原时间点，Grid/Road使用时间最近保留点（平局取更早），长度和event mask保持原样，在同event索引比较层ID/tuple及AMI。它测插值扰动稳定性，不是删点后不同token时间支持的采样鲁棒性；训练无此目标。

## 对改进的优先级建议（未执行的新实验）

**优先1：先分离HV量化目标与梯度隔离。** 保留HV全部前向、局部VQ目标、辅助梯度、码本、数据和预算，仅替换最终重构ST。基线u=z_g；实验u=z_g+(z_grid−sg(z_grid))+(z_road−sg(z_road))，decoder输入仍为u+sg(s4−u)。前向数值仍s4，后向三分支各收到一次重构梯度。这样改变的是重构可达性，不是加入连续旁路；码本仍由局部VQ训练。必须另记梯度尺度增加，不能把改善全归因于“冲突解决”；若有信号，加GPS-only增益控制u=z_g+(sqrt(3)−1)(z_g−sg(z_g))，它只匹配latent级理想总梯度尺度，不保证参数级范数匹配。先tokenizer级比较秩、码分布、G00和probe，健康/重构有改善才付出LLM训练成本；通过条件沿用原健康门槛、G00恶化≤10%，最终仍须主误差≥5%且配对区间支持改善。

**优先2：处理所有组共有的后层低利用，和优先1分开。** 以H1/B2为实用参照，先做“仅训练数据驱动的逐层残差码本初始化”对照：冻结初始化encoder、只用train latent，C1拟合第一目标，再按已定前缀生成后层残差，固定K/d与原更新方式、训练预算。与随机初始化单独比较，禁止同时加EMA、死码重置、归一化或熵正则。若需要连续预训练→冻结encoder拟合码本→严格离散decoder训练，应另立实验，记录每段预算/权重/冻结状态，并设置等总预算控制；它不是初始化方式的单因素变更。更多active code不必然更好，必须联合perplexity、最大占比、重构与生成。

**优先3：利用LF“真实码位置重构较好、生成后较差”的线索。** 先固定tokenizer和原训练adapter评估协议，分析每条轨迹SID错码与解码误差的关系，区分长度/序号偏移与码语义差异；关联不当作因果。后续若改成按event联合预测tuple、重排层序或调整层损失，只改变一种生成机制，保持码本/decoder不变，并保留全人口G11、unigram参照及tuple评估。当前不据此直接更换LLM或增加tokenizer容量。

**暂缓项：** 不直接加入AttnRes/mHC、拼接替换或多项正则。累计前缀probe没有出现随深度退化，量化向量诊断也不支持广泛残差抵消，当前缺少优先针对“覆盖”的证据。SimVQ与Rotation Trick仅作为后续独立候选，已核对原论文的适用机制，见`literature_options.md`；本轮没有验证其GPS收益。

下一轮如果得到健康且有收益的候选，再执行配置中禁用的seed314159/20260907重复；本轮不自动追加训练。健康门槛没有通过的当前HV不直接扩规模。H1保留作对照，并保留B2防止把辅助前缀调整的低NLL误认为真实收益。
