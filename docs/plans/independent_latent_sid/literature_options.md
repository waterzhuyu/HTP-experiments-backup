# 当前量化问题的两类文献参照（2026-09-17）

目的：把已观测问题映射到可区分的消融，不替代HV/LF/H1/B2的最终比较。本文为文献与代码分析，无新训练、无数据或模型修改、无新实验指标。

**码本参数化：SimVQ。** 作者将码字写成C·W，以共享可学习线性基更新整个码本空间；算法1采用高斯初始化并冻结C。实验覆盖图像和音频。来源：[论文v3，方法4节和算法1](https://arxiv.org/html/2411.02038v3)。这些结果未验证本项目的GPS多视图条件残差量化。

对本项目的推断：可保持每层K、64维和四SID协议，仅改变码本参数化，检查“低频码缺少有效更新”是否关键。但需记录初始化、可训练参数量和码本更新路径的伴随变化；如果采用固定C+可训练W，就不能声称只加了一个无影响的Linear。最好分离“原初始化+学习W”和“论文初始化+固定C”以明确归因。由于当前连续latent已低秩，这个改动不保证恢复丢失的信息，应先看LF是否同样低秩。

**量化梯度：Rotation Trick。** 作者保持前向最近邻量化值，用detach后的旋转与缩放把encoder输出映射到码字，改变反向梯度传递；Jacobian为(||q||/||e||)R。来源：[论文v2，第4.1节](https://arxiv.org/html/2410.06424v2)。它与改变码本容量是不同干预，不直接提供视图分工保证。

对本项目的推断：若LF/HV差异主要伴随STE几何错配，可先只替换最终GPS decoder的ST路径（e=z_gps，q=s4），保持三辅助ST与局部VQ损失不变；再单独研究辅助head路径，不一次改全部梯度。还需明确零范数、数值精度、累积前缀和原单层方法的差异。当前s4/z_gps平均范数比约0.20，用这种方法会同时缩小某些梯度；因此实际梯度大小/方向都需重测。该判断是本项目的推断，并非原论文对HV的结论。

目前建议顺序仍待对照结果：先看LF连续latent/probe是否比HV健康→区分表征学习、码本更新、STE传递三类问题→挑一个匹配证据的改动。连续预训练+冻结量化（上一报告候选）改变训练日程，应与以上两种参数化/梯度干预分别实验。不得同时拼接SimVQ、Rotation、usage正则和更大K后把收益归因于“独立latent”。

所有候选保持原训练/validation划分，不使用验证latent初始化码本；最终decoder只读离散SID；验收仍包含重构、G11主误差/有效率、前缀probe、tuple熵和NLL相对unigram收益。论文的图像/音频结果仅为机制参照，不是本项目效果证据。
